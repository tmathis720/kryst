# Migration: 0.x to 1.0

| 0.x | 1.0 |
| --- | --- |
| `Preconditioner::direct_solve(op, b, x, comm)` | `direct_solve(op, b, x)` |
| `LinearSolver::solve(a, pc, b, x)` | `solve(a, pc, b, x, side, comm, monitors, work)` |
| `MatOpPreconditioner` | `LegacyOpPreconditioner` (feature `legacy-pc-bridge`) |
| Options built in solver | Options → builders, deferred PCs, chaining |

## Distributed matrix API migration (ParCSR → DistCsrOp)

- Canonical distributed runtime path is `matrix::DistCsrOp`.
- Legacy `matrix::parcsr::ParCsrMatrix` now delegates runtime apply to an
  internal canonical `DistCsrOp`.
- Legacy ParCSR internals (`a_diag`, `a_off`, `colmap_*`, legacy halo access,
  and partition helpers) are deprecated since `1.1.0` and are planned for
  removal after **2026-12-31**.
- New code should:
  - build distributed operators with `DistCsrOp::from_local_rows(...)`;
  - use `DistCsrOp::partition_rows_balanced(...)` for ownership partitions;
  - consume `LinOp::dist_layout()` / `LinOp::comm()` instead of legacy
    diag/off internals.
